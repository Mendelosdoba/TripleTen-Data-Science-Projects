
Gold Recovery Prediction — Project Summary

This project focuses on predicting gold recovery rates at different stages of an industrial gold extraction process. Using historical sensor and process data, I analyzed the flotation and purification stages, validated recovery calculations, handled missing and anomalous values, and trained regression models to predict both rougher and final gold recovery. Model performance was evaluated using sMAPE, with an emphasis on accuracy and robustness across process stages. The project demonstrates practical experience with industrial datasets, feature selection, model evaluation, and business-oriented interpretation of results.
