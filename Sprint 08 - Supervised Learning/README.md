# Supervised Learning Project

## Overview
This project applies supervised machine learning techniques to solve a classification problem using real-world data. The goal is to build and evaluate models that accurately predict the target outcome.

## Methods
- Data preprocessing and feature preparation  
- Train/validation/test split  
- Model training (Logistic Regression, Decision Tree, Random Forest)  
- Hyperparameter tuning  
- Evaluation using F1 score and ROC-AUC  

## Results
The final model achieved strong predictive performance and met the project’s evaluation requirements.
